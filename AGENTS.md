# AGENTS

Shared guide for autonomous contributors in `mycelial-empire`.

## Project Overview

A Vite + React + TypeScript simulation of an underground fungal colony. Managing resource flows, network growth, and procedural exploration.

- **Package Manager**: `npm`
- **Build**: `npm run build`
- **Typecheck**: `npm run typecheck`
- **Lint**: `npm run lint`
- **Test**: `npm run test`
- **Dev**: `npm run dev`

## Core Directives

- **Spec-Driven**: Always follow the Analyze → Design → Implement cycle.
- **Memory Bank**: Keep `/memory` synchronized with every task.
- **Handoffs**: Always provide a PR summary with Goal, Key Changes, and Validation results.
