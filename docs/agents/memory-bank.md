# Memory Bank & Standards

Usage policies for the repository's Memory Bank and documentation standards.

## Memory Bank Usage

- Decisions and updates should be logged in the relevant `memory/tasks/TASK###-*.md` file for traceability.
- Reflect updates in `memory/activeContext.md` and `memory/progress.md` to keep context current.
- Architectural shifts should be captured in `memory/systemPatterns.md` and `memory/techContext.md`.
- Update `memory/projectbrief.md` for significant mission or scope changes.

## ID Reservation Rules

- **Tasks:** Sequential integers (e.g., `TASK001`). Check `memory/tasks/` and `memory/tasks/COMPLETED/` for uniqueness.
- **Designs:** Sequential integers (e.g., `DES001`). Check `memory/designs/` and `memory/designs/COMPLETED/` for uniqueness.

## Standards

- Complements `.github/instructions/spec-driven-workflow-v1.instructions.md` and `.github/instructions/memory-bank.instructions.md`.
- Decisions and updates should also be reflected in memory files like `activeContext.md` and `progress.md` to keep context current.
